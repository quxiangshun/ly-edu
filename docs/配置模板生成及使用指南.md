# LyEdu 配置模板生成及使用指南

本文档介绍 LyEdu 后端程序（lyedu-api-python）的**配置模板机制**：程序运行时自动在 `~/.lyedu/conf` 目录下生成 `config.ini.template` 模板文件，提示用户复制为 `config.ini` 后填写配置，避免误覆盖已有配置，同时保留清晰的模板参考。

**适用读者**：希望在自己项目中实现类似配置管理机制的开发者，或需要理解 LyEdu 配置流程的用户。

---

## 一、思路与背景

### 1.1 为什么要这样做？

| 问题 | 传统做法 | 本方案 |
|------|----------|--------|
| 首次运行无配置 | 直接生成 config.ini，可能覆盖用户已有配置 | 只生成 config.ini.template 模板，用户手动复制后填写 |
| 用户不知如何配置 | 缺少说明，容易填错 | 模板内有详细注释，每个配置项有说明 |
| 打包交付时配置位置 | 配置文件可能在程序目录，难找 | 固定使用 `~/.lyedu/conf`，跨平台统一 |
| 配置目录权限 | 默认权限可能导致泄露 | 目录权限 0o700，仅当前用户可读写 |

### 1.2 核心流程

```
程序启动
    │
    ▼
检查 ~/.lyedu/conf/config.ini 是否存在？
    │
    ├─ 存在 ──► 加载 config.ini，校验后使用
    │
    └─ 不存在 ──► 创建 ~/.lyedu/conf 目录
                    │
                    ▼
               生成 config.ini.template 模板
                    │
                    ▼
               项目目录有 .env 或 .env.dev？
                    │
                    ├─ 有 ──► 使用 .env 继续（开发模式）
                    │
                    └─ 无 ──► 打印复制与编辑指引，退出
```

### 1.3 配置优先级

1. **`~/.lyedu/conf/config.ini`**（优先）：适用于打包交付、生产部署
2. **`.env` / `.env.dev`**（备选）：适用于本地开发

## 二、在另一套项目中实现的步骤

以下步骤可直接在 Cursor 或任意 Python 项目中操作，按顺序执行即可。

### 步骤 1：创建 `lyedu_config.py` 模块

在项目根目录（与 main.py 同级）新建文件 `lyedu_config.py`，填入以下完整代码：

```python
# -*- coding: utf-8 -*-
"""
LyEdu 配置模板生成及加载

配置路径：~/.lyedu/conf/
- config.ini.template：模板文件（程序自动生成，用户参考）
- config.ini：实际配置文件（用户复制模板后填写）

优先使用 config.ini；若不存在则生成 config.ini.template 并提示用户复制后修改。
"""
import configparser
import os
import sys
from typing import Optional, Tuple


def get_config_paths() -> Tuple[str, str, str]:
    """
    获取配置相关路径：
    - config_dir: 用户根目录/.lyedu/conf
    - template_path: 模板文件路径 ~/.lyedu/conf/config.ini.template
    - config_path: 实际配置文件路径 ~/.lyedu/conf/config.ini
    """
    user_home = os.path.expanduser("~")
    config_dir = os.path.join(user_home, ".lyedu", "conf")
    template_path = os.path.join(config_dir, "config.ini.template")
    config_path = os.path.join(config_dir, "config.ini")
    return config_dir, template_path, config_path


def generate_config_template(template_path: str) -> None:
    """生成配置模板文件"""
    template_content = """# LyEdu 配置模板文件
# 请将此文件复制为 config.ini 并填写实际的 MySQL/Redis 配置
# 保存路径：~/.lyedu/conf/config.ini

[mysql]
# MySQL 服务器地址（必填）
host = 127.0.0.1
# MySQL 端口（必填，默认 3306）
port = 3306
# MySQL 用户名（必填）
user = root
# MySQL 密码（无密码则留空）
password = your_mysql_password_here
# 数据库名（必填）
database = lyedu
# 字符集（建议 utf8mb4）
charset = utf8mb4

[redis]
# Redis 服务器地址（必填）
host = 127.0.0.1
# Redis 端口（必填，默认 6379）
port = 6379
# Redis 数据库编号（必填，默认 0）
db = 0
# Redis 密码（无密码则留空）
password = your_redis_password_here
"""
    with open(template_path, "w", encoding="utf-8") as f:
        f.write(template_content)
    print(f"[LyEdu] 配置模板已生成：{template_path}")


def _validate_config(config: configparser.ConfigParser) -> None:
    """校验配置项合法性"""
    if not config.has_section("mysql") or not config.has_section("redis"):
        raise ValueError("配置文件缺少 [mysql] 或 [redis] 节点")

    mysql_required = ["host", "port", "user", "database"]
    redis_required = ["host", "port", "db"]

    for item in mysql_required:
        value = config.get("mysql", item, fallback="").strip()
        if not value:
            raise ValueError(f"MySQL 配置项 '{item}' 不能为空")

    for item in redis_required:
        value = config.get("redis", item, fallback="").strip()
        if not value:
            raise ValueError(f"Redis 配置项 '{item}' 不能为空")

    try:
        mysql_port = config.getint("mysql", "port")
        redis_port = config.getint("redis", "port")
        if not (1 <= mysql_port <= 65535) or not (1 <= redis_port <= 65535):
            raise ValueError("端口号必须在 1-65535 之间")
    except ValueError as e:
        if "invalid literal" in str(e).lower():
            raise ValueError("MySQL/Redis 端口必须是 1-65535 之间的整数") from e
        raise


def load_config_ini(config_path: str) -> configparser.ConfigParser:
    """从 config.ini 加载配置，校验通过后返回 ConfigParser"""
    config = configparser.ConfigParser()
    config.read(config_path, encoding="utf-8")
    _validate_config(config)
    return config


def ensure_config_or_exit() -> bool:
    """
    确保有可用的配置来源：
    - 若 ~/.lyedu/conf/config.ini 存在：返回 True，调用方需从 config.ini 加载
    - 若不存在：创建目录、生成 config.ini.template，若无 .env 则退出

    返回 True 表示应使用 config.ini，False 表示应使用 .env（若存在）
    """
    config_dir, template_path, config_path = get_config_paths()

    if os.path.exists(config_path):
        return True

    # config.ini 不存在：确保目录存在
    if not os.path.exists(config_dir):
        try:
            os.makedirs(config_dir, mode=0o700)
            print(f"[LyEdu] 配置目录已创建：{config_dir}")
        except PermissionError:
            print(f"[LyEdu] 无权限创建配置目录 {config_dir}，请以管理员身份运行")
            sys.exit(1)
        except OSError as e:
            print(f"[LyEdu] 创建配置目录失败：{e}")
            sys.exit(1)

    # 生成模板
    generate_config_template(template_path)

    # 检查项目目录是否有 .env 或 .env.dev（开发环境可继续）
    from pathlib import Path
    _config_dir = Path(__file__).resolve().parent
    has_env = (_config_dir / ".env").exists() or (_config_dir / ".env.dev").exists()

    if not has_env:
        print("\n[LyEdu] 未找到配置文件，请执行以下操作：")
        if sys.platform.startswith("win"):
            print(f'  1. 复制模板：copy "{template_path}" "{config_path}"')
        else:
            print(f"  1. 复制模板：cp {template_path} {config_path}")
        print(f"  2. 编辑配置：打开 {config_path} 填写 MySQL/Redis 信息")
        print("  3. 重新运行程序")
        sys.exit(1)

    return False


def apply_config_ini_to_environ(config: configparser.ConfigParser) -> None:
    """将 config.ini 内容写入 os.environ，供 config 模块后续读取"""
    mysql = config["mysql"]
    redis = config["redis"]
    os.environ["MYSQL_HOST"] = mysql.get("host", "localhost").strip()
    os.environ["MYSQL_PORT"] = str(mysql.getint("port", 3306))
    os.environ["MYSQL_USERNAME"] = mysql.get("user", "root").strip()
    os.environ["MYSQL_USER"] = mysql.get("user", "root").strip()
    os.environ["MYSQL_PASSWORD"] = mysql.get("password", "").strip()
    os.environ["MYSQL_DATABASE"] = mysql.get("database", "lyedu").strip()
    os.environ["MYSQL_CHARSET"] = mysql.get("charset", "utf8mb4").strip()
    os.environ["REDIS_HOST"] = redis.get("host", "localhost").strip()
    os.environ["REDIS_PORT"] = str(redis.getint("port", 6379))
    os.environ["REDIS_DB"] = str(redis.getint("db", 0))
    pw = redis.get("password", "").strip()
    os.environ["REDIS_PASSWORD"] = pw if pw else ""
```

### 步骤 2：修改 `config.py`（或你的主配置模块）

在**配置模块最开头**（在 `load_dotenv` 之前）插入以下逻辑：

```python
# ========== LyEdu 固定配置目录：~/.lyedu/conf/config.ini ==========
# 若 config.ini 存在则优先使用；不存在则生成 config.ini.template，无 .env 时退出
import lyedu_config
if lyedu_config.ensure_config_or_exit():
    _, template_path, config_path = lyedu_config.get_config_paths()
    try:
        cfg = lyedu_config.load_config_ini(config_path)
        lyedu_config.apply_config_ini_to_environ(cfg)
    except Exception as e:
        print(f"[LyEdu] 配置文件格式错误：{e}")
        print(f"[LyEdu] 请参考模板文件 {template_path} 检查配置格式")
        sys.exit(1)
# 已设置 MYSQL_*、REDIS_* 到 os.environ，后续 load_dotenv 不会覆盖
```

**说明**：`load_dotenv()` 默认不覆盖已存在的环境变量，因此 config.ini 的内容会优先生效。

### 步骤 3：为 MySQL / Redis 添加连接超时（可选但推荐）

在 MySQL 连接处增加 `connect_timeout=10`：

```python
# db.py 或等效连接代码
conn = pymysql.connect(
    host=config.MYSQL_HOST,
    port=config.MYSQL_PORT,
    # ... 其他参数
    connect_timeout=10,  # 防止程序卡死
)
```

在 Redis 连接处增加 `connect_timeout=10`：

```python
_client = redis.Redis(
    host=config.REDIS_HOST,
    port=config.REDIS_PORT,
    # ... 其他参数
    connect_timeout=10,
)
```

## 三、用户使用说明（交付给最终用户）

以下内容可放到 README 或用户手册中，供不熟悉开发的用户按步骤操作。

### 3.1 首次运行程序

1. 直接运行程序（如 `lyedu_backend.exe` 或 `python main.py`）。
2. 若未找到 `config.ini`，程序会自动创建 `~/.lyedu/conf` 目录，并生成 `config.ini.template` 模板文件。

### 3.2 复制并编辑配置文件

**Windows（CMD 或 PowerShell）：**

```cmd
copy "%USERPROFILE%\.lyedu\conf\config.ini.template" "%USERPROFILE%\.lyedu\conf\config.ini"
```

**Linux / macOS：**

```bash
cp ~/.lyedu/conf/config.ini.template ~/.lyedu/conf/config.ini
```

**编辑配置文件**，填写实际的 MySQL 和 Redis 信息：

- Windows：记事本打开 `%USERPROFILE%\.lyedu\conf\config.ini`
- Linux/macOS：`vim ~/.lyedu/conf/config.ini` 或任意文本编辑器

### 3.3 重新运行程序

配置填写完成后，重新运行程序即可正常连接数据库。

### 3.4 注意事项

- `~/.lyedu` 是隐藏文件夹：
  - **Windows**：文件资源管理器 → 查看 → 勾选「隐藏的项目」
  - **Linux/macOS**：`ls -a ~` 可查看隐藏目录
- 若提示权限错误，Linux/macOS 可执行：`chmod 700 ~/.lyedu/conf`

## 五、适配到其他项目时的改动建议

| 项目差异 | 建议改动 |
|----------|----------|
| 配置路径不同（如 `~/.myapp/conf`） | 修改 `get_config_paths()` 中的 `".lyedu"` 为你的应用名 |
| 只需要 MySQL，不需要 Redis | 在 `_validate_config` 中移除 Redis 校验，在 `apply_config_ini_to_environ` 中移除 Redis 相关 |
| 需要更多配置节（如 `[jwt]`） | 在模板内容、`_validate_config`、`apply_config_ini_to_environ` 中增加对应逻辑 |
| 使用 .env 为主，不想引入 config.ini | 不引入 lyedu_config，保持原有 dotenv 逻辑即可 |

## 六、总结

| 要点 | 说明 |
|------|------|
| **核心流程** | 程序自动创建配置目录 → 生成模板文件 → 提示用户复制为 config.ini → 填写后重新运行 |
| **用户友好** | 根据系统给出精准的复制命令，模板文件注释清晰，降低操作门槛 |
| **安全性** | 配置目录权限 0o700，仅当前用户可访问；严格配置校验，防止无效配置导致异常 |
| **兼容性** | 开发环境可继续使用 .env；打包交付时使用 ~/.lyedu/conf/config.ini |
