# 飞书通讯录同步 - 完整实现（部门 + 用户 + 覆盖）

本文档提供**完整逻辑与可复制代码**，便于在另一套系统中通过 Cursor 实现：同步飞书部门、同步飞书用户、以及「覆盖已存在」的全部能力。

**文档说明**：本文档来自**另一套系统（course）**的飞书同步实现说明，作为在其它项目（如 ly-edu、xjty_enterprise_asset 等）中实现时的参考。不同项目需按自身表结构、数据库（同步/异步）、Token 类型等做适配，详见文末**第六节**。

## 三、数据表与模型要求

同步逻辑依赖以下表结构（表名、字段名需与代码一致，或你自行改代码中的引用）：

- **departments**：id, name, code(唯一), parent_id, status, sort, created_at, updated_at, created_by, updated_by, del_flag
- **department_closures**：id, ancestor_id, descendant_id, distance（外键 departments.id）
- **users**：id, username(唯一), password, name, email, phone, avatar, dept_id, status, created_at, updated_at, created_by, updated_by, del_flag
- **user_oauth**：id, user_id, provider, provider_user_id, provider_username, union_id, open_id, created_at, updated_at, created_by, updated_by, del_flag
- **roles**：id, name, code(唯一), del_flag, ...
- **user_roles**：id, user_id, role_id, created_at, updated_at, created_by, updated_by, del_flag

**部门编码规则**：飞书同步的部门 `code` 以 `FS_` + 飞书部门ID 存储（如 `FS_od-xxx`），用于存在性判断与闭包表范围。

**若无数据权限模块**：同步服务中使用了 `async with DataScopeDisabled():`。若你系统没有数据权限，可在任意模块（如 `core/data_scope.py`）中提供空实现：

```python
# 例如 core/data_scope.py
class DataScopeDisabled:
    async def __aenter__(self):
        return self
    async def __aexit__(self, *args):
        pass
```

使用时保持 `async with DataScopeDisabled():` 不变即可。若完全不做数据权限过滤，也可以删除所有 `async with DataScopeDisabled():`，只保留其内部的 `stmt = select(...)` 与 `await db.execute(stmt)`。

### 4.1 飞书 OAuth（获取 app_access_token）

**路径建议**：`app/core/feishu_oauth.py`（或 `core/feishu_oauth.py`）

```python
"""
飞书 OAuth - 通讯录同步只需 get_app_access_token
"""
import httpx
from typing import Optional
from loguru import logger

# 从你的配置读取，例如 from app.core.config import settings
try:
    from app.core.config import settings
except ImportError:
    class settings:
        FEISHU_APP_ID = ""  # 或 os.getenv("FEISHU_APP_ID", "")
        FEISHU_APP_SECRET = ""

APP_ACCESS_TOKEN_URL = "https://open.feishu.cn/open-apis/auth/v3/app_access_token/internal"


class FeishuOAuthService:
    @classmethod
    async def get_app_access_token(cls) -> Optional[str]:
        async with httpx.AsyncClient() as client:
            try:
                response = await client.post(
                    APP_ACCESS_TOKEN_URL,
                    json={
                        "app_id": settings.FEISHU_APP_ID,
                        "app_secret": settings.FEISHU_APP_SECRET,
                    },
                    timeout=10.0,
                )
                result = response.json()
                response.raise_for_status()
                if result.get("code") == 0:
                    return result.get("app_access_token")
                logger.error(f"[飞书] 获取app_access_token失败: {result.get('msg')}")
                return None
            except Exception as e:
                logger.error(f"[飞书] 获取app_access_token异常: {e}")
                return None
```

### 4.2 飞书通讯录 API（部门 / 用户列表）

**路径建议**：`app/core/feishu_contact.py`

```python
"""
飞书通讯录 - 获取部门列表、用户列表
"""
import httpx
from typing import Optional, List, Dict, Any
from loguru import logger

from app.core.feishu_oauth import FeishuOAuthService

DEPARTMENT_CHILDREN_URL = "https://open.feishu.cn/open-apis/contact/v3/departments/{department_id}/children"
USER_LIST_URL = "https://open.feishu.cn/open-apis/contact/v3/users"


class FeishuContactService:
    @classmethod
    async def get_all_departments(cls) -> List[Dict[str, Any]]:
        app_access_token = await FeishuOAuthService.get_app_access_token()
        if not app_access_token:
            logger.error("[飞书通讯录] 获取app_access_token失败")
            return []
        all_departments = []
        await cls._get_departments_recursive(app_access_token, "0", all_departments)
        logger.info(f"[飞书通讯录] 共获取 {len(all_departments)} 个部门")
        return all_departments

    @classmethod
    async def _get_departments_recursive(
        cls,
        app_access_token: str,
        parent_department_id: str,
        result_list: List[Dict[str, Any]],
    ):
        children = await cls._get_department_children(
            app_access_token, parent_department_id
        )
        for dept in children:
            result_list.append(dept)
            await cls._get_departments_recursive(
                app_access_token,
                dept.get("department_id", ""),
                result_list,
            )

    @classmethod
    async def _get_department_children(
        cls,
        app_access_token: str,
        department_id: str,
        page_size: int = 50,
    ) -> List[Dict[str, Any]]:
        async with httpx.AsyncClient() as client:
            try:
                url = DEPARTMENT_CHILDREN_URL.format(department_id=department_id)
                params = {
                    "user_id_type": "open_id",
                    "department_id_type": "department_id",
                    "fetch_child": "false",
                    "page_size": page_size,
                }
                response = await client.get(
                    url,
                    headers={"Authorization": f"Bearer {app_access_token}"},
                    params=params,
                    timeout=30.0,
                )
                result = response.json()
                if result.get("code") == 0:
                    return result.get("data", {}).get("items", [])
                logger.error(f"[飞书通讯录] 获取子部门失败: {result.get('msg')}")
                return []
            except Exception as e:
                logger.error(f"[飞书通讯录] 获取子部门异常: {str(e)}")
                return []

    @classmethod
    async def get_all_users(cls) -> List[Dict[str, Any]]:
        app_access_token = await FeishuOAuthService.get_app_access_token()
        if not app_access_token:
            return []
        all_users = []
        page_token = None
        while True:
            users, next_page_token = await cls._get_users_page(
                app_access_token, page_token
            )
            all_users.extend(users)
            if not next_page_token:
                break
            page_token = next_page_token
        logger.info(f"[飞书通讯录] 共获取 {len(all_users)} 个用户")
        return all_users

    @classmethod
    async def _get_users_page(
        cls,
        app_access_token: str,
        page_token: Optional[str] = None,
        page_size: int = 50,
    ) -> tuple:
        async with httpx.AsyncClient() as client:
            try:
                params = {
                    "user_id_type": "open_id",
                    "department_id_type": "department_id",
                    "page_size": page_size,
                }
                if page_token:
                    params["page_token"] = page_token
                response = await client.get(
                    USER_LIST_URL,
                    headers={"Authorization": f"Bearer {app_access_token}"},
                    params=params,
                    timeout=30.0,
                )
                result = response.json()
                if result.get("code") == 0:
                    data = result.get("data", {})
                    return data.get("items", []), data.get("page_token")
                return [], None
            except Exception as e:
                logger.error(f"[飞书通讯录] 获取用户列表异常: {str(e)}")
                return [], None

    @classmethod
    async def get_department_users(cls, department_id: str) -> List[Dict[str, Any]]:
        app_access_token = await FeishuOAuthService.get_app_access_token()
        if not app_access_token:
            return []
        all_users = []
        page_token = None
        while True:
            users, next_page_token = await cls._get_department_users_page(
                app_access_token, department_id, page_token
            )
            all_users.extend(users)
            if not next_page_token:
                break
            page_token = next_page_token
        return all_users

    @classmethod
    async def _get_department_users_page(
        cls,
        app_access_token: str,
        department_id: str,
        page_token: Optional[str] = None,
        page_size: int = 50,
    ) -> tuple:
        async with httpx.AsyncClient() as client:
            try:
                params = {
                    "user_id_type": "open_id",
                    "department_id_type": "department_id",
                    "department_id": department_id,
                    "page_size": page_size,
                }
                if page_token:
                    params["page_token"] = page_token
                response = await client.get(
                    USER_LIST_URL,
                    headers={"Authorization": f"Bearer {app_access_token}"},
                    params=params,
                    timeout=30.0,
                )
                result = response.json()
                if result.get("code") == 0:
                    data = result.get("data", {})
                    return data.get("items", []), data.get("page_token")
                return [], None
            except Exception as e:
                logger.error(f"[飞书通讯录] 获取部门用户异常: {str(e)}")
                return [], None
```

### 4.4 同步服务（部门 + 用户 + 覆盖 + 闭包表）

**路径建议**：`app/modules/system/services/feishu_sync_service.py`

说明：

- 将 `app.core`、`app.modules.system`、`app.modules.auth` 等替换为你的项目包名。
- 若没有 `DataScopeDisabled`，按第三节提供空实现，或删除所有 `async with DataScopeDisabled():`，只保留内部的查询逻辑。

```python
"""
飞书通讯录同步服务 - 部门 + 用户 + 覆盖
"""
import re
import random
from typing import Dict, List
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession
from loguru import logger

from app.core.feishu_contact import FeishuContactService
from app.core.security import get_password_hash
from app.core.data_scope import DataScopeDisabled
from app.modules.system.models.department import Department, DepartmentClosure
from app.modules.auth.models.user import User
from app.modules.auth.models.user_oauth import UserOAuth
from app.modules.auth.models.user_role import UserRole
from app.modules.auth.models.role import Role
from app.modules.system.schemas.feishu_sync import FeishuSyncStats


class FeishuSyncService:
    @classmethod
    async def sync_contacts(
        cls,
        db: AsyncSession,
        *,
        sync_departments: bool = True,
        sync_users: bool = True,
        overwrite_existing: bool = False,
        current_user_id: int = None,
    ) -> tuple:
        stats = FeishuSyncStats()
        errors = []
        dept_id_mapping = {}
        try:
            if sync_departments:
                dept_stats, dept_errors, dept_id_mapping = await cls._sync_departments(
                    db,
                    overwrite_existing=overwrite_existing,
                    current_user_id=current_user_id,
                )
                stats.departments_created = dept_stats["created"]
                stats.departments_updated = dept_stats["updated"]
                stats.departments_skipped = dept_stats["skipped"]
                stats.departments_failed = dept_stats["failed"]
                errors.extend(dept_errors)
            if sync_users:
                user_stats, user_errors = await cls._sync_users(
                    db,
                    dept_id_mapping=dept_id_mapping,
                    overwrite_existing=overwrite_existing,
                    current_user_id=current_user_id,
                )
                stats.users_created = user_stats["created"]
                stats.users_updated = user_stats["updated"]
                stats.users_skipped = user_stats["skipped"]
                stats.users_failed = user_stats["failed"]
                errors.extend(user_errors)
        except Exception as e:
            logger.error(f"[飞书同步] 同步过程异常: {str(e)}")
            errors.append(f"同步过程异常: {str(e)}")
        return stats, errors

    @classmethod
    async def _sync_departments(
        cls,
        db: AsyncSession,
        *,
        overwrite_existing: bool = False,
        current_user_id: int = None,
    ) -> tuple:
        stats = {"created": 0, "updated": 0, "skipped": 0, "failed": 0}
        errors = []
        dept_id_mapping = {}
        try:
            feishu_depts = await FeishuContactService.get_all_departments()
            if not feishu_depts:
                return stats, errors, dept_id_mapping
            dept_codes = [
                f"FS_{d.get('department_id')}"
                for d in feishu_depts
                if d.get("department_id")
            ]
            stmt = select(Department).where(Department.code.in_(dept_codes))
            result = await db.execute(stmt)
            existing_dept_map = {dept.code: dept for dept in result.scalars().all()}
            for feishu_dept in feishu_depts:
                try:
                    dept_id = feishu_dept.get("department_id", "")
                    dept_name = feishu_dept.get("name", "")
                    if not dept_id or not dept_name:
                        stats["skipped"] += 1
                        continue
                    dept_code = f"FS_{dept_id}"
                    existing_dept = existing_dept_map.get(dept_code)
                    if existing_dept:
                        if overwrite_existing:
                            existing_dept.name = dept_name
                            if current_user_id:
                                existing_dept.updated_by = current_user_id
                            stats["updated"] += 1
                        else:
                            stats["skipped"] += 1
                        dept_id_mapping[dept_id] = existing_dept.id
                    else:
                        new_dept = Department(
                            name=dept_name,
                            code=dept_code,
                            parent_id=0,
                            status=1,
                            sort=0,
                            created_by=current_user_id,
                            updated_by=current_user_id,
                        )
                        db.add(new_dept)
                        await db.flush()
                        dept_id_mapping[dept_id] = new_dept.id
                        stats["created"] += 1
                except Exception as e:
                    errors.append(
                        f"同步部门 {feishu_dept.get('name', 'Unknown')} 失败: {str(e)}"
                    )
                    stats["failed"] += 1
            await db.commit()
            dept_ids_to_update = [
                dept_id_mapping[d.get("department_id")]
                for d in feishu_depts
                if d.get("department_id") in dept_id_mapping
            ]
            if dept_ids_to_update:
                stmt = select(Department).where(Department.id.in_(dept_ids_to_update))
                result = await db.execute(stmt)
                depts_to_update = {dept.id: dept for dept in result.scalars().all()}
                for feishu_dept in feishu_depts:
                    dept_id = feishu_dept.get("department_id", "")
                    parent_dept_id = feishu_dept.get("parent_department_id", "0")
                    if (
                        parent_dept_id
                        and parent_dept_id != "0"
                        and parent_dept_id in dept_id_mapping
                        and dept_id in dept_id_mapping
                    ):
                        local_dept_id = dept_id_mapping[dept_id]
                        local_parent_id = dept_id_mapping[parent_dept_id]
                        dept = depts_to_update.get(local_dept_id)
                        if dept:
                            dept.parent_id = local_parent_id
            await db.commit()
            logger.info("[飞书同步] 开始重建部门闭包表...")
            try:
                await cls._rebuild_department_closure(db, dept_id_mapping)
            except Exception as e:
                logger.error(f"[飞书同步] 重建闭包表失败: {str(e)}")
                errors.append(f"重建闭包表失败: {str(e)}")
        except Exception as e:
            logger.error(f"[飞书同步] 同步部门过程异常: {str(e)}")
            errors.append(f"同步部门过程异常: {str(e)}")
            await db.rollback()
        return stats, errors, dept_id_mapping

    @classmethod
    async def _rebuild_department_closure(
        cls, db: AsyncSession, dept_id_mapping: Dict[str, int]
    ) -> None:
        if dept_id_mapping:
            local_dept_ids = list(dept_id_mapping.values())
            await db.execute(
                DepartmentClosure.__table__.delete().where(
                    (DepartmentClosure.descendant_id.in_(local_dept_ids))
                    | (DepartmentClosure.ancestor_id.in_(local_dept_ids))
                )
            )
        stmt = select(Department).where(Department.code.like("FS_%"))
        result = await db.execute(stmt)
        all_depts = result.scalars().all()
        if not all_depts:
            return
        for dept in all_depts:
            await cls._build_closure_for_dept(db, dept, all_depts)
        await db.commit()

    @classmethod
    async def _build_closure_for_dept(
        cls, db: AsyncSession, dept: Department, all_depts: List
    ) -> int:
        count = 0
        check_stmt = select(DepartmentClosure).where(
            (DepartmentClosure.ancestor_id == dept.id)
            & (DepartmentClosure.descendant_id == dept.id)
            & (DepartmentClosure.distance == 0)
        )
        if (await db.execute(check_stmt)).scalar_one_or_none() is None:
            db.add(
                DepartmentClosure(
                    ancestor_id=dept.id, descendant_id=dept.id, distance=0
                )
            )
            count += 1
        ancestors = cls._get_ancestors(dept.parent_id, all_depts)
        for ancestor, distance in ancestors:
            check_stmt = select(DepartmentClosure).where(
                (DepartmentClosure.ancestor_id == ancestor.id)
                & (DepartmentClosure.descendant_id == dept.id)
                & (DepartmentClosure.distance == distance)
            )
            if (await db.execute(check_stmt)).scalar_one_or_none() is None:
                db.add(
                    DepartmentClosure(
                        ancestor_id=ancestor.id,
                        descendant_id=dept.id,
                        distance=distance,
                    )
                )
                count += 1
        return count

    @classmethod
    def _get_ancestors(cls, parent_id: int, all_depts: List) -> List:
        if parent_id == 0:
            return []
        parent = next((d for d in all_depts if d.id == parent_id), None)
        if parent is None:
            return []
        ancestors = [(parent, 1)]
        ancestors.extend(
            [
                (a, d + 1)
                for a, d in cls._get_ancestors(parent.parent_id, all_depts)
            ]
        )
        return ancestors

    @classmethod
    async def _sync_users(
        cls,
        db: AsyncSession,
        *,
        dept_id_mapping: Dict[str, int] = None,
        overwrite_existing: bool = False,
        current_user_id: int = None,
    ) -> tuple:
        stats = {"created": 0, "updated": 0, "skipped": 0, "failed": 0}
        errors = []
        dept_id_mapping = dept_id_mapping or {}
        try:
            feishu_users = await FeishuContactService.get_all_users()
            if len(feishu_users) <= 5:
                stmt = select(Department).where(Department.code.like("FS_%"))
                result = await db.execute(stmt)
                departments = result.scalars().all()
                feishu_dept_ids = [
                    dept.code[3:]
                    for dept in departments
                    if dept.code.startswith("FS_")
                ]
                user_map = {}
                for dept_id in feishu_dept_ids:
                    try:
                        for user in await FeishuContactService.get_department_users(
                            dept_id
                        ):
                            oid = user.get("open_id")
                            if oid and oid not in user_map:
                                user_map[oid] = user
                    except Exception as e:
                        logger.error(f"[飞书同步] 获取部门 {dept_id} 用户失败: {e}")
                feishu_users = list(user_map.values())
            if not feishu_users:
                return stats, errors
            stmt = select(UserOAuth).where(UserOAuth.provider == "feishu")
            result = await db.execute(stmt)
            all_oauth = result.scalars().all()
            oauth_by_union_id = {
                oauth.union_id: oauth for oauth in all_oauth if oauth.union_id
            }
            oauth_by_open_id = {oauth.open_id: oauth for oauth in all_oauth if oauth.open_id}
            user_ids = [o.user_id for o in all_oauth]
            users_by_id = {}
            if user_ids:
                async with DataScopeDisabled():
                    stmt = select(User).where(User.id.in_(user_ids))
                    result = await db.execute(stmt)
                    users_by_id = {u.id: u for u in result.scalars().all()}
            async with DataScopeDisabled():
                stmt = select(User.username)
                result = await db.execute(stmt)
                existing_usernames = {row[0] for row in result.all()}
            stmt = select(Role).where(Role.code == "USER", Role.del_flag == 0)
            result = await db.execute(stmt)
            default_role = result.scalar_one_or_none()
            default_role_id = default_role.id if default_role else None
            new_users = []
            for feishu_user in feishu_users:
                try:
                    open_id = feishu_user.get("open_id", "")
                    name = feishu_user.get("name", "")
                    if not open_id or not name:
                        stats["skipped"] += 1
                        continue
                    union_id = feishu_user.get("union_id")
                    email = feishu_user.get("email", "")
                    mobile = feishu_user.get("mobile", "")
                    if mobile and mobile.startswith("+"):
                        if mobile.startswith("+86"):
                            mobile = mobile[3:]
                        elif mobile.startswith("+1"):
                            mobile = mobile[2:]
                        else:
                            m = re.match(r"^\+(\d{2,3})(\d{7,})$", mobile)
                            if m:
                                mobile = m.group(2)
                    avatar_url = (
                        feishu_user.get("avatar", {}).get("avatar_240")
                        if isinstance(feishu_user.get("avatar"), dict)
                        else None
                    )
                    dept_id = None
                    department_ids = feishu_user.get("department_ids", [])
                    if department_ids:
                        dept_id = dept_id_mapping.get(department_ids[0])
                    existing_oauth = (
                        oauth_by_union_id.get(union_id) if union_id else None
                    )
                    if existing_oauth is None:
                        existing_oauth = oauth_by_open_id.get(open_id)
                    if existing_oauth:
                        user = users_by_id.get(existing_oauth.user_id)
                        if not user:
                            errors.append(f"用户 {name} 的OAuth存在但用户已删除")
                            stats["failed"] += 1
                            continue
                        if overwrite_existing:
                            user.name = name
                            if email:
                                user.email = email
                            if mobile:
                                user.phone = mobile
                                if user.username != mobile:
                                    if mobile not in existing_usernames:
                                        existing_usernames.discard(user.username)
                                        user.username = mobile
                                        existing_usernames.add(mobile)
                                    else:
                                        logger.warning(
                                            f"[飞书同步] 用户 {name} 手机号 {mobile} 已被占用，保留原用户名"
                                        )
                            if avatar_url:
                                user.avatar = avatar_url
                            if dept_id is not None:
                                user.dept_id = dept_id
                            if current_user_id:
                                user.updated_by = current_user_id
                            if union_id:
                                existing_oauth.union_id = union_id
                            existing_oauth.open_id = open_id
                            if current_user_id:
                                existing_oauth.updated_by = current_user_id
                            if default_role_id:
                                async with DataScopeDisabled():
                                    stmt = (
                                        select(UserRole)
                                        .where(
                                            UserRole.user_id == user.id,
                                            UserRole.del_flag == 0,
                                        )
                                        .limit(1)
                                    )
                                    result = await db.execute(stmt)
                                    if result.scalar_one_or_none() is None:
                                        db.add(
                                            UserRole(
                                                user_id=user.id,
                                                role_id=default_role_id,
                                                created_by=current_user_id,
                                                updated_by=current_user_id,
                                            )
                                        )
                            stats["updated"] += 1
                        else:
                            stats["skipped"] += 1
                    else:
                        username = mobile or (
                            (email.split("@")[0] if email else f"feishu_{open_id[:8]}")
                        )
                        if not username:
                            username = f"feishu_{open_id[:8]}"
                        if username in existing_usernames:
                            username = f"{username}_{random.randint(1000, 9999)}"
                        existing_usernames.add(username)
                        new_user_data = {
                            "username": username,
                            "password": get_password_hash("Lyedu@123"),
                            "name": name,
                            "email": email or None,
                            "phone": mobile or None,
                            "avatar": avatar_url,
                            "dept_id": dept_id,
                            "status": 1,
                            "created_by": current_user_id,
                            "updated_by": current_user_id,
                            "open_id": open_id,
                            "union_id": union_id,
                        }
                        new_users.append(new_user_data)
                        stats["created"] += 1
                except Exception as e:
                    errors.append(
                        f"同步用户 {feishu_user.get('name', 'Unknown')} 失败: {str(e)}"
                    )
                    stats["failed"] += 1
            batch_size = 100
            for i in range(0, len(new_users), batch_size):
                batch = new_users[i : i + batch_size]
                for user_data in batch:
                    open_id = user_data.pop("open_id")
                    union_id = user_data.pop("union_id")
                    new_user = User(**user_data)
                    db.add(new_user)
                    await db.flush()
                    db.add(
                        UserOAuth(
                            user_id=new_user.id,
                            provider="feishu",
                            provider_user_id=open_id,
                            provider_username=user_data["name"],
                            union_id=union_id,
                            open_id=open_id,
                            created_by=current_user_id,
                            updated_by=current_user_id,
                        )
                    )
                    if default_role_id:
                        db.add(
                            UserRole(
                                user_id=new_user.id,
                                role_id=default_role_id,
                                created_by=current_user_id,
                                updated_by=current_user_id,
                            )
                        )
            await db.commit()
        except Exception as e:
            logger.error(f"[飞书同步] 同步用户过程异常: {str(e)}")
            errors.append(f"同步用户过程异常: {str(e)}")
            await db.rollback()
        return stats, errors
```

## 五、逻辑摘要（部门 + 用户 + 覆盖）

- **部门同步**  
  - 拉取飞书全量部门（从根 `0` 递归子部门）。  
  - 本地部门编码：`FS_` + 飞书 `department_id`；已存在则按「是否覆盖」决定是否更新 `name`，不存在则创建，`parent_id` 先置 0。  
  - 第二次遍历按 `parent_department_id` 更新 `parent_id`，再重建部门闭包表（仅飞书部门相关记录）。

- **用户同步**  
  - 优先全量用户列表；若数量 ≤5 则按部门逐个拉取并按 `open_id` 去重。  
  - 通过本地 `user_oauth`（provider=feishu）用 `union_id`/`open_id` 判断是否已存在。  
  - **已存在**：`overwrite_existing=True` 时更新姓名、邮箱、手机、头像、部门及 OAuth，并可选补默认角色；否则跳过。  
  - **新用户**：用户名优先手机号（去国家码），冲突则加随机后缀；初始密码加密；写入用户表 + user_oauth + 默认角色（code=USER）。

- **覆盖**  
  - 由请求参数 `overwrite_existing` 控制：为 True 时对已存在的部门和用户执行上述更新逻辑。

按第四节放置并调整包名、数据权限后，即可在另一套系统中通过 Cursor 实现飞书同步部门、用户及覆盖的全部功能。

## 六、文档核查与其它项目适配要点

本节基于对 course 文档的核查，以及在 ly-edu 等项目中的实现经验，列出**与 course 的差异**和**适配时需注意的点**，便于在其它系统中正确复用。

### 6.1 通讯录 API 与 Token

- **course 文档**：使用 `app_access_token`（4.1、4.2 中 FeishuOAuthService.get_app_access_token）。
- **飞书官方**：通讯录相关接口（部门、用户列表）推荐使用 **tenant_access_token**（企业维度）。若在其它项目中遇到权限或拉取为空，可改为使用 tenant_access_token（`/auth/v3/tenant_access_token/internal`）。
- **ly-edu**：已使用 tenant_access_token，对应 `util/feishu_api.py` 中的 `_get_tenant_access_token()`。

### 6.2 部门拉取方式

- **course 文档**：仅使用「获取子部门」接口（`/contact/v3/departments/{department_id}/children`）从根 `0` 递归，无其它 list 接口。
- **注意**：飞书**没有**「按父部门 ID 查询子部门列表」的通用 GET 接口（如 `/contact/v3/department/list` 会 404）。在其它项目中**只应使用 children 接口递归**，不要对无子部门的父部门再调不存在的 list 接口，否则会产生大量 404。

### 6.3 用户与部门关联

- **course 文档**：用户表有 `dept_id`，同步时从飞书用户 `department_ids` 取第一个，经 `dept_id_mapping` 映射后写入；覆盖时 `if dept_id is not None: user.dept_id = dept_id`。
- **在其它项目中**：必须保证「用户信息同步要关联部门」——即根据飞书返回的 `department_ids`（或单值 `department_id`/`open_department_id`）映射到本地部门 ID，写入用户表的部门字段；覆盖时若飞书无部门，应支持将本地部门置空（NULL）。

### 6.4 无闭包表、无 user_oauth 的项目（如 ly-edu）

- **course 文档**：部门表有 `code`（FS_ + 飞书部门ID）、有 `department_closures`；用户通过 `user_oauth`（provider=feishu，union_id/open_id）匹配。
- **适配方式**：  
  - 部门：可用 `feishu_department_id` 等字段关联飞书部门，无需 `code` 与闭包表；两阶段写库（先 parent_id=0 建映射，再按 parent_department_id 更新 parent_id）保持一致。  
  - 用户：可在用户表上直接存 `feishu_open_id`、`union_id`，用其匹配飞书用户，无需单独 user_oauth 表；新用户可不设密码（仅飞书登录）。

### 6.5 接口与响应

- **course 文档**：POST `/feishu/sync/contacts` 同步调用；GET `/feishu/sync/test` 测连接（app_access_token）。
- **在其它项目中**：可增加 `?background=1` 异步执行、GET `/feishu/sync/task/{task_id}` 轮询结果，避免长耗时超时；响应格式保持 `success`、`message`、`stats`、`errors` 即可。

## 七、本项目（ly-edu）同步逻辑与实现

本节描述 **ly-edu** 当前采用的同步方式与代码位置，便于维护与在其它项目中复用相同逻辑。

### 7.1 同步方式概述

1. **先同步所有部门**：从飞书根部门 `0` 递归拉取全部部门（仅用「获取子部门」接口），再写入本系统。
2. **再按部门拉取用户**：遍历每个已建立映射的飞书部门，调用「部门下用户」接口（含子部门），按 `open_id` 去重后逐条处理用户。
3. **部门 ID 与缓存**：本系统部门以 `feishu_department_id` 与飞书对应；同步用户前构建「飞书部门 ID → 本地部门 id」缓存，写用户时用缓存解析所属部门，避免多次查库，保证效率。

### 7.2 只同步部门

- **匹配**：仅根据 `feishu_department_id` 查询（`department_service.get_by_feishu_department_id`）。
- **覆盖=true**：已存在则更新该记录（name、sort、parent_id 等）。
- **覆盖=false**：已存在则跳过，不存在则插入。
- **两阶段写库**：第一次遍历先以 `parent_id=0` 创建/更新并建立映射；第二次遍历按 `parent_feishu_id` 更新 `parent_id`。

### 7.3 只同步用户

- **拉取方式**：仍按部门维度拉取——用缓存中的飞书部门 id 列表，逐个调用飞书「部门下用户」接口（`fetch_child=True`），再按 `open_id` 去重；不处理、不写入部门数据。
- **部门 id**：用户所属部门从缓存 `feishu_department_id -> 本地 id` 解析，不重复查库。
- **唯一性**：以**手机号**判断是否存在（`user_service.find_by_mobile`）；无手机号时用 `union_id`、`feishu_open_id` 匹配。
- **存在**：覆盖则更新（姓名、昵称、手机、邮箱、头像、部门等）；不覆盖则跳过。
- **不存在**：插入新用户（用户名优先手机号，不设密码，仅飞书登录）。
